# Support

- For installation and usage instructions, start with the [README](./README.md).
- For a reproducible bug or feature proposal, search existing [GitHub issues](https://github.com/M003aad/DevEye/issues) before opening a new one.
- For suspected security vulnerabilities, use the private reporting process in [SECURITY.md](./SECURITY.md), not a public issue.
- For contribution questions, see [CONTRIBUTING.md](./CONTRIBUTING.md).

DevEye is maintained on a best-effort basis. Include the extension version, browser version, and steps to reproduce when requesting help. Do not post private information or credentials.

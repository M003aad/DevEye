# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.0 | Yes |

Only the current release line is supported with security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use [GitHub Private Vulnerability Reporting](https://github.com/M003aad/DevEye/security/advisories/new) or email **188705139+M003aad@users.noreply.github.com**. Include the affected version, a description of the issue, steps to reproduce it, and any relevant impact. Do not include real user data or credentials.

## Response and remediation

The maintainer aims to acknowledge reports within 7 calendar days and provide an initial assessment within 14 calendar days. Confirmed issues will be prioritized by severity, with a target patch within 30 calendar days where feasible. Complex fixes may take longer; the reporter will be updated when timelines change. Coordinate public disclosure with the maintainer so users have a reasonable opportunity to update.
